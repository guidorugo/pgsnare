Check a configuration and report every problem

Usage: pgsnare config check [OPTIONS] --config <FILE>

Options:
  -c, --config <FILE>
          The configuration file to check

      --allow-insecure-file-permissions
          Report a file that holds secrets and can be read by other users as a warning and not as an error. `pgsnare run` starts with such files when it is given the same option

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

The check loads the configuration and its token files, looks at the access
rights of the files that hold secrets, reads the certificates and keys, and
builds the event sinks, with the code that `pgsnare run` uses. It reports every
problem it finds, and warns about settings that are valid and give up some
protection.

The check reads the files and the environment variables the configuration
names, such as the signing key of a webhook. Run it as the user and with the
environment pgsnare runs with.

Nothing is connected to, no listener is opened and no file is created or
written. So the check cannot know whether an address is free, whether a
database, a webhook receiver or a syslog server answers, or whether the file of
a file sink that is not there yet can be created. `pgsnare run` can still fail
on these after a check that passed.

The exit status is 0 if pgsnare would start with this configuration, also when
there are warnings, and 1 if it would not.

Example:
  pgsnare config check --config /etc/pgsnare/pgsnare.yaml
